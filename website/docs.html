Quick start / version 1.0.0

From install to first recall.

This is the shortest verified path through the current CLI. The repository remains the source for complete API, security, deployment, and integration documentation.

01 / Install 02 / Initialize 03 / Run 04 / Connect MCP 05 / Use Python 06 / Production

01. Install the runtime

Lummenna supports Python 3.10 through 3.12. The verified source-install path below includes the optional model-export and MCP dependencies.

git clone https://github.com/QuantmindSSI/lummenna.git
cd lummenna
python3 -m venv .venv
source .venv/bin/activate
pip install -e '.[mcp,export]'

For development tooling as well, install pip install -e '.[dev,mcp,export]'.

02. Initialize the palace

lummenna init --device generic
LUMMENNA_SOVEREIGN=false lummenna model download bge-small-en-v1.5

The one-time model command downloads from Hugging Face and exports with the optional toolchain, so sovereign mode must be explicitly disabled for that command. Air-gapped installations must place a compatible model.onnx and tokenizer files under ~/.lummenna/models/bge-small-en-v1.5/ before isolation.

lummenna memory store "We chose SQLite for the cache layer" --room decisions
lummenna memory retrieve "cache layer"

03. Run the application

lummenna serve

# Main observatory: http://localhost:8848/
# Stable alias:     http://localhost:8848/dashboard
# API reference:   http://localhost:8848/docs

The server and dashboard are Community features. Production startup requires a real local embedding model. LUMMENNA_ALLOW_MOCK_EMBEDDER=1 exists only for tests and UI development; semantic results in that mode are not meaningful.

04. Connect an MCP client

The MCP server exposes seven tools: lummenna_search, lummenna_store, lummenna_assemble, lummenna_turn, lummenna_feedback, lummenna_status, and lummenna_dashboard.

{
  "mcpServers": {
    "lummenna": {
      "command": "python",
      "args": ["-m", "lummenna.integrations.mcp_server"]
    }
  }
}

Client-specific examples are maintained in the repository's integrations directory.

05. Use the Python API

from lummenna.config import LummennaConfig
from lummenna.data.schema import get_connection
from lummenna.force.mnemonic.store import store_memory

config = LummennaConfig()
conn = get_connection(config)
chunk_id = store_memory(
    conn,
    content="User prefers concise status updates",
    room_name="preferences",
    config=config,
)
conn.close()

LangChain and LangGraph adapters are optional extras. The REST API publishes its runtime schema at /openapi.json.

06. Prepare production deliberately

Set an API key, choose an encryption mode where required, mount persistent storage and model volumes, and keep the service on loopback unless network access is intentional.

export LUMMENNA_API_KEY='replace-with-a-secret'
export LUMMENNA_DATABASE_ENCRYPTION_MODE='sqlcipher'
export LUMMENNA_ENCRYPTION_KEY='replace-with-a-separate-secret'
lummenna serve --host 127.0.0.1

Encryption-at-rest and non-default tenant isolation require a valid Pro entitlement. Read the deployment guide and security policy before exposing the API.
