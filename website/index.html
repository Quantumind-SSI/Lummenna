Local-first memory and context framework

Memory, illuminated locally.

Lummenna gives agents a structured memory palace, hybrid lexical and vector retrieval, token-budgeted context assembly, and a managed memory lifecycle. The default runtime stays on your hardware; network-backed operations are explicit configuration choices.

01 / Why

A memory system with an inspectable shape.

Each statement below maps to an implementation in the repository. Optional services and commercial controls are named rather than hidden behind broad claims.

01 / Structure

Rooms, loci, chunks

Memories carry location, provenance, validity, value, and retrieval state instead of living in an undifferentiated vector collection.

Community
02 / Retrieval

Signals, then fusion

SQLite FTS5, dense vectors, optional graph traversal, and reciprocal rank fusion form the retrieval path.

Community
03 / Context

Budgeted assembly

Retrieved memories are ranked and assembled into a bounded prompt context with explicit truncation behavior.

Community
04 / Lifecycle

Retention has pressure

Time decay, interference, and budget-driven precision changes prevent an unbounded store from masquerading as useful memory.

Community
05 / Interfaces

Use the same palace

Enterprise boundaries
